## 一句话定位

把主流 AI 产品名当成**词源小品**：天体拉丁文、诗歌体裁阶梯、科幻火星语、博弈论、庄子中道……看出「用旧文明最高概念给新技术起名」的浪漫；顺带立 flag：**Claude 下一档或叫 Saga**。

## 适合谁

- 想快速记住 Claude / Gemini / Grok / Kimi / MiniMax / Midjourney / 混元 各自命名逻辑的人  
- 做产品/Bot 起名、想借镜「文艺 vs 理工」两套路的人  
- 不适合：要厂商官方命名新闻稿或商标检索结论的人（本片是词源随笔）

## 上手顺序（建议 10–15 分钟）

1. 读本目录 `transcript.md`（硬字幕校对稿）——海外下不了抖音时以此为准。  
2. 有大陆抖音 App 再打开短链对照口播；B 站同片可作备用观看。  
3. 记一张「命名路线图」表（见下）即可对外复述。  
4. 若自己要起名：先选路线（天体 / 文学阶梯 / 科幻词 / 算法 / 哲学），再压测试读音与梗。

## 可复制金句 / 论点

- 「我们就这么拿着旧世界的群星、诗歌和故事，给新世界起名字。」  
- 「人类文明渺小而庄重的浪漫感。」（作者借刘慈欣笔调概括）  
- 「有人翻拉丁文，有人翻诗集，有人翻科幻小说，有人翻博弈论，有人翻庄子——他们一直心生敬意，等着我们出生。……等会儿。」  
- 命名 flag：「Claude Saga，我先立个 flag。」  
- 账号起源：「盖工人呢？——哦，搞咒语去了。」

## 坑（必看）

1. **抖音成片箱内拉不下来**：勿把「未得抖音 ASR」当成有口播；本稿依据 **B 站同片硬字幕**。  
2. **作者随笔 ≠ 厂商官宣**：Gemini「两团队」等说法以厂商公开叙述为准再引用。  
3. **Luna / Terra / Sol**：硬字幕如此；勿写成 Terror / Soar（ASR 误听）。  
4. **Claude 下一档叫 Saga** 是作者预测 flag，不是 Anthropic 公告。  
5. **豆包彩蛋**主要靠口播收尾；硬字幕停在「等会儿」——引用时标明口播。  
6. 非洲语言吸气音段是**喜剧钩子**，不是语言学课；勿当严肃语料。
