# Agent-Autoloop 开源：事件驱动的 Agent 自动化中台

来源：数字生命卡兹克 · 2026-11-04 · https://mp.weixin.qq.com/s/T9_acg247gxzUNL4j5zrCw · 仓库 https://github.com/KKKKhazix/agent-autoloop

## 一句话
把"事件→派活→Agent执行→交付→人批奏折"做成一个约1600行、零依赖的 Node 内核 + 四类插件（事件/Agent/通道/交付），Agent 能自己闭环的不打扰人，危险操作才发卡片让人拍板。

## 流程
1. 事件：定时、GitHub Issue/PR、业务报错等，统一成标准事件送进内核。
2. 派活：rules.json 决定交给哪个 Agent、哪个目录、哪个 Skill；短时间重复事件合并成一轮。
3. 执行：Agent 在**最后一条回复**里交代结果，可附 ```agent-autoloop {json}``` 块（ask 提问/通知/结卡/约复查/唤醒下一步）。不需 SDK。
4. 分流：能自理的自动完成或定时复查；删数据、重启、花钱、对外发消息→发卡片（飞书/桌面/Slack等），人点按钮后续接原对话。

## 内核四原则（只做：收事件、按规则分活、派给 Agent、记录每一步）
- 内核不外连、不写死产品名（有测试守边界）→ 逻辑确定性。
- **挂起零消耗**：等审批时存档下班，不轮询、不烧 Token，人回复后读档续跑，同一问题不问第二遍。
- **事件溯源**：只追加账本，写入成功才回"收到"；幂等去重，断网重发不重复执行；`agent-autoloop why <轮次>` 追溯原因/规则版本/机器/结果。
- **指令数据分离**：外部内容（Issue、同事意见）放文件里标为"资料"，权限以本机 rules.json 为准，防 Prompt 注入。
- **跳数熔断**：Agent 互相唤醒每跳+1，超 8 层停并通知（参考网络 TTL）；此前 Codex 审 Claude 限 3 轮。

## 插件
- 事件：GitHub、定时、轮询小脚本（无新内容直接退出、不唤醒模型）。
- Agent：Claude Code、Codex、ACP；任何"命令行接一段话吐结果"的都能一行配置接入。
- 通道：默认桌面通知；飞书卡片自用；钉钉/企微/Slack/Discord 可接。
- 交付：PR 打 `deliver` 标签→审码、等 CI、合并、等发布、线上验版本；`deliver-review` 只审。规则只认主干，PR 代码不在本机跑。

## 安装
把仓库丢给 Claude Code/Codex："先读 README 和 INSTALL.md 装好并试跑，要我选的转给我，跑通后帮我写第一条规则"。INSTALL.md 是写给 Agent 看的。

## 作者在跑的例子（=一条规则+一个 Skill）
1. 每天下午全网（微信群/X/小红书/抖音）搜 AIHOT 口碑，出报告+建议。
2. 每周操控浏览器问豆包/DeepSeek/千问/元宝/ChatGPT/Gemini，看是否推荐 AIHOT（GEO 监测）。
3. 每晚 10 点巡厂商信源核对 Token 羊毛/免费额度上下架。
4. 每早 10 点模型价格榜对官网校正。
5. 每 5 分钟外部探活，挂了才唤醒 Codex。
6. 每周日"大扫除"删重复代码/个案补丁/残留，再上线。
- 公司"虚实中台"：同事飞书私聊机器人提意见→Claude 评估/修改/上线/回复，敏感的找人拍板；80+ 条意见，约 70 条自主完成，十几条人批，可自动的 1 小时内上线。

## 对 Keith 的启发
- 审批卡片 + 存档续跑 = 我们"不可逆操作需批准"规则的工程化版本。
- 外部内容当资料不当指令 = 与 untrusted fence 同理。
- GEO 周巡、价格/信源对账、探活零成本，可直接映射到 Roblox/gptradar 站的 routine。
- 注意：作者自称 1.0.0、设计出身，存在 BUG 可能；性能数据为作者自测。
