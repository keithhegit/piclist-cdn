# 用 Gemini 反向扮演谷歌评审员：E-E-A-T 倒推补内容

> 来源：想要变壮的will《反向用Gemini做SEO太恐怖了，网站流量开挂》（2026-08-04 20:31 北京时间 = 2026-08-04 05:31 PT）· [原文](https://mp.weixin.qq.com/s/btzaN0k6V79RAnarpXtKXw) · 逐段精要见 `transcript.md`

## 一句话定位

别先堆文案：把产品页丢给 Gemini，让它按 Google Search Quality Rater 的 E-E-A-T 四维打分找扣分点，再针对性补「真用过」细节、第三方信源与站内可信度信息，改完用同一指令复测。文中「72 小时上首页 / 流量近 8 倍」为作者案例说法。

## 上手顺序

1. **选一页卡住的核心落地页**（作者案例：常规优化两轮无效、长期停在较后页的产品页）。  
2. **跑评审提示词**：按 E-E-A-T 四维打分（满分 10）+ 逐维扣分原因。  
3. **补经验性**：用第二段提示词生成可证明「真用过」的具体使用场景（换成自己 niche 的细节）。  
4. **补权威性**：加检测报告 / 认证 / 外部评测等可点击验证的外链。  
5. **补可信度**：作者署名与背景、联系方式、退换货、公司信息等「站级」信号。  
6. **同一指令复测**：对比改前改后分数，确认缺口关闭后再发布/等收录。  
7. **（可选）用 Cursor / Grok Bot** 把「评审 → 补洞 → 复测」做成固定工作流，批量扫多站页面。

## 可复制提示词 / 金句

**提示词 1 — E-E-A-T 评审（原文）**

```
请以Google Search Quality Rater Guidelines的E-E-A-T标准，从经验性、专业性、权威性、可信度四个维度对这段内容打分（满分10），并具体指出每个维度扣分的原因。
```

**提示词 2 — 补经验性细节（原文；使用时替换「以下参数」与场景举例）**

```
基于以下参数，补充3个具体的真实使用场景细节（比如高海拔火力衰减下的实际烧水时间、连续使用后的耐磨情况），要求细节具体到能证明'真的用过'。
```

## 坑 / 注意

- **结果不可直接照搬**：72 小时、首页第 1、近 8 倍流量为作者单案例说法，无公开数据核验；可能含时效、站龄、外链等未交代变量。  
- **「真用过」细节勿瞎编**：若捏造使用体验，可能伤害 E-E-A-T 与用户信任；应用真实测试/用户反馈改写。  
- **专业性维度文中着墨少**：五步里经验/权威/可信写得细，专业性主要靠评审打分暴露，需自行按行业补资质与深度。  
- **站级信号要真上线**：作者署名、联系方式、政策页不能只写在提示词里。  
- **复测很重要**：同一指令对比前后分，避免只改文案不关缺口。  
- **合规**：第三方报告/认证需有权引用；联盟/广告站另注意披露（原文未谈变现层）。

## 适合谁

- 做出海独立站 / 产品页 SEO、内容「看起来专业但排名不动」的人。  
- 运营 Roblox 攻略/工具等多站 SEO 矩阵者：可把 E-E-A-T 评审做成页面质检 checklist，再补真实游玩/使用细节与作者页。  
- 用 Gemini / Cursor / Grok Bot 做内容与站务自动化的人：提示词可直接进 agent 流水线。  
- 不适合：指望单靠提示词「72 小时开挂」、或不愿补真实信源与站内信任页的人。
