## 一句话定位

物业打工人用 **DeepSeek API 按量付费**搭一条云端定时管道，每天 7 点产出《AI日报·严选24H》并归档飞书——近 30 天约 **22.3 元（≈每天七毛四）**，真正难点不是技术，是你读不读、筛不筛。

## 上手顺序

1. **先手动跑通一次**：只挑 2–3 个你真会看的源，让 AI 抓一次、筛一次，你确认会读再用。
2. **再谈定时与自动化**：云端挂定时任务调 DeepSeek；推送卡片 + 飞书知识库归档。
3. **立筛选铁律**：每条入选必须接到你正在做的某件具体事；接不上 →「今日略过」；零条也合格，凑数才失败。
4. **可选双轨**：云端 DeepSeek 当抓取苦力；本地 Claude Code 读知识库，生成带行动清单的执行日报。
5. **顺序别反**：先验证你会读，再花钱让它每天跑。

## 可复制点

1. **上手顺序金句**：先验证你会读，再花钱让它每天跑。
2. **筛选铁律**：入选资讯必须接到正在做的具体事；多数日子只留 2–3 条，零条也合格。
3. **双轨分工**：抓取花小钱（DeepSeek）/ 筛选与行动清单走订阅本地模型（文中为 Claude Code）。
4. **价值口径**：反对「烧完没产出」；一个月 9200 万 tokens 换「真会打开的日报」才算账。
5. **荀子引文**（DeepSeek 公告转引，可作态度便签）：不诱于誉，不恐于诽，率道而行，端然正己。

## 坑

- 管道跑通后最大坑：**送上门的日报你不读** → 无限信息流变成有限信息流，焦虑换地址。
- 抓取层会反复挂（Twitter、热点接口、GitHub 超时、飞书文档被跳登录页）；别把「必须登录」误写成规则——先换真浏览器验证。
- 账单/「斩杀线」评测会过时；价格与模型能力以你自己后台与官方为准。
- 文中未给出完整可复制仓库/脚本；要细节需向作者追问或自搭。

## 适合谁

- 时间碎片化、必须跟 AI 资讯、但不想亲手刷 Twitter/HN 的副业者。
- 想用低价 API 搭「日更管道」、并建立「少而接事」筛选习惯的人。
- 关心 DeepSeek 实际账单与稳定性（而非只看评测图）的人。

不适合：只想要现成 RSS 订阅、不愿意自己定「接到哪件具体事」筛子的人。
