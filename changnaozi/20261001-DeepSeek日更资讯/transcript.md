昨天的 AI 圈发生了什么 GitHub 上哪个新项目冒头了 推特上我关注的那十几个人说了什么。已经筛过一遍 分好了六个板块。

起因 我受够了自己刷

我是个物业行业打工人。白班加夜班 用夜里的碎片时间做 AI 副业。做副业就得跟上行业信息 但我的时间根本不够刷。

7 月底我说过一句话。我学的内容需要自己去推特或平台搜查 这太浪费时间了。直接你帮我自动跑这个任务就行。

于是这个活被我外包了。不是外包给人 是外包给一条自动管道。云端服务器上挂一个定时任务 调 DeepSeek 的 API 按用量付费 每天定点去抓这些源

TechCrunch VentureBeat 两家科技媒体

Hacker News 程序员社区热榜

GitHub 每日热门项目

Product Hunt 新产品发布平台

推特上十几个固定账号 Anthropic OpenAI 独立开发者 levelsio 这些

抓回来之后不是全塞给我 而是先过筛子。分成六个板块 核心大事件 生产力工具站 GitHub 开源热门 闷声发财产品雷达 Show HN 精选 AI 前沿技术追踪。

每天早上 7 点 推送卡片加飞书归档 雷打不动。这套管道到 7 月中旬已经跑了 83 次 现在还在每天跑。

平均一天七毛四。这还是整个账户的全部消费 连日报之外的杂活都算进去了。从我开通到现在 累计总共也就花了 302 块。

我在生财有术听人讲过一天烧掉 100 亿 tokens 的玩法。当时我的原话是

你做一堆垃圾产品出来 我觉得是没有价值的。首先你要烧 token 如果烧到上亿 token 的话 你的产出和这个项目首先得是有价值的。

我不反对烧 token 我反对的是烧完没产出。这条管道一个月 9200 万 tokens 22 块钱 换回来的是每天早上一份我真的会打开的日报。这笔账我算得过来。

便宜之外 真正留住我的是稳

一个月跑下来 这条管道断过很多次。但断的全是别人。

推特的抓取通道隔三差五失效 热点搜索接口曾经连挂七天。GitHub 热榜在我的网络下偶发超时 抓一次不行得再试一次。还有一次抓公开的飞书文档 命令行被跳转到登录页 差点把必须登录当结论写进规则。换真浏览器一试 直接就读到了。

数据源塌了又修 修了又塌。一个月折腾下来 唯独中间那一环 DeepSeek 的模型调用 一次都没断过 一次问题都没出过。

DeepSeek 除了便宜就是稳。这种稳定 有一种莫名的让人踏实。

对搭自动化管道的人来说 稳比强更重要。日报是每天早上 7 点要见人的 模型今天抽风明天限流 整条管道就是摆设。1834 次调用零故障 这个数字比任何评测榜单都有说服力。因为它是我自己的账单。

我账单里的这个模型 上周成了圈里的斩杀线

截图里那个被我调用了 747 次的 deepseek-v4-flash 上周正式版上线。这几天在 X 和国内平台被吵翻了 讨论围绕一个词。AI 时代的斩杀线。

意思是 比它贵的模型未必比它强 比它弱的模型没它便宜。这条线以下的大多数模型 被它直接划进了淘汰区。有报道说 仅 OpenCode 一个平台 它一天就被烧掉 8 万亿 tokens。

评测机构 Artificial Analysis 那张图流传得最广。横轴是每个任务的成本 纵轴是智能分。从 V4 Flash 0731 的位置拉两条虚线 右下方一大片区域整个变红。红区里的模型 分数没它高 价格比它贵。能逃出这条线的 只剩几家大厂最顶级的旗舰。

![img](https://mmbiz.qpic.cn/sz_mmbiz_png/oIQL0FjlVPNkq2EoAibibbvaaZJxGbNQJUT4UtKlVgAuxWAqNxnicNVWrb8wUkJiaUqag8icP8mUtzk7ibPd292hPX9vQoUaQ7l8lWoOEWlj75oMA/640?wx_fmt=png&from=appmsg)

它还把百万 tokens 上下文 一次能读完整个代码仓库的记忆容量 从旗舰模型的专属配置下放到了这个轻量版上。DeepSeek 官方公告的标题就叫 迈入百万上下文普惠时代。

看热闹的人在转评测图 我看的是自己的账单。这个斩杀线模型 过去一个月一直在我的管道里每天干活。干满一个月 22 块 3。所谓普惠 落到我这个物业打工人头上 就是这么具体。

DeepSeek 在 V4 发布公告的结尾 引了荀子里的一句话

不诱于誉 不恐于诽 率道而行 端然正己。

不被夸奖带偏 不被骂声吓住 按自己认定的路走 把自己的事做正。这句话是他们说给自己的。但我这种每天七毛钱的小用户 是这句话最直接的受益者。

最大的坑不在技术 送上门的日报你会看吗

管道跑通之后 真正的问题才冒出来。每天 36 条资讯准时送到 如果我不读 那只是把无限的信息流换成了有限的信息流。刷不完的推特变成了读不完的日报 时间没省下来 焦虑换了个存放地址。

所以后来立了一条筛选铁律。每条入选的资讯 必须能接到我正在做的某件具体的事上。接不上的 写得再热闹也扔进今日略过。执行下来 多数日子真正入选的只有两三条 有时候是零条。零条也算合格 凑数才算失败。

日报的价值不在多 在筛。筛子就是你自己正在做的事。

现在这件事每天替我省下大约 2 个小时。以前这些时间用来自己刷自己搜 现在用来干活。

下一步

这条管道现在是双轨。云端 DeepSeek 继续当抓取苦力 本地的 Claude Code 每天早上读我的知识库 把资讯和我手头的事对上号 生成一份带行动清单的执行日报。抓取花小钱 筛选走订阅 两边各干各的擅长的。

如果你也想搭一条 不用一步到位。先手动跑通一次。挑两三个你真会看的源 让 AI 抓一次筛一次 你看完觉得有用 再谈定时和自动化。

顺序别反 先验证你会读 再花钱让它每天跑。
