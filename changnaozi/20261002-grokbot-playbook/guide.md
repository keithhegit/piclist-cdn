## 一句话定位

把《Grok Bot 橙皮书》与 Awesome 清单合成一本可点选的「玩法全景手册」：讲清 Grok Bot ≠ Grok 聊天、怎么免费试用入门、总监模式 / Routine / Auto-review、以及大量可抄案例与提示词。

## 上手顺序（试用额度只做这三件）

1. **跑通一个闭环**：今天本就要干的小事 → 派活 → 云端干活 → 交作业。
2. **大脑倾倒 + 反向配置**：把自己背景灌进去，再用魔法提问让它建 Bot 编制。
3. **示范一条最短 Routine**：五步以内固定流程，当面做一遍再让它独立重演。

试用期不要急着拉五人舰队，也不要先上长链条自动化。

## 能力表（机制速查）

| 机制 | 你要记住的 |
|---|---|
| Bot | 云端电脑 + 会用界面的 AI 队友，不是对话框聊天 |
| 幕僚长 CoS | 所有任务先丢给它，由它拆解派发追踪 |
| Routine / Teach | 示范一遍固化；Teach 录屏最多 10 分钟不录麦 |
| Auto-review | 支付 / 敏感 / 不确定必弹卡；低风险可预先 Always allow |
| 安全边界 | **Bots are not a security boundary**——隔离按账号不按 Bot |
| 广告/外发 | 外发仍应等人点头；密钥走 secret card |
| MCP | 仅公网 HTTPS/SSE；不支持本地/stdio |
| 写码 | 转交 Cursor Cloud Agent；可用 GitHub / Origin 管 PR |

## 魔法提问（可复制）

```
基于你对我的了解，如果是你，你会怎么设置这个工作台？
应该建立哪几个 Bot？它们的职位、职责和日常例行工作是什么？
```

## 八个官方级玩法提示词（摘要入口）

完整原文在手册第 08 章 / usegrokbot.com。角色骨架：

1. 幕僚长：周复盘、派活、标不可逆动作；未授权不登录新工具  
2. 收件箱/日历：先只读；发信/拒会/下单前等人点头  
3. 研究侦察：一手源 + URL；标明传闻 vs 可忽略  
4. 工程复现：开单不合并、不推 main  
5. 值班客服：只依帮助文档；不退款不贴密钥  
6. Teach 固化：写前置条件、点击路径、失败模式、审批点  
7. 旅行管家：付钱/绑会员/不可免费取消前必须停  
8. 订阅断舍离：先台账后取消，取消后截图存档  

## 省钱四心法

任务分层（Routine / 轻量 Bot / 主力）→ 能 Routine 就 Routine → 验收标准前置 → 盯住每周额度重置节奏。  
周额度溢到 On-Demand **无应用内警告** → 可把 On-Demand 上限设 `$0`。

## 坑（必读）

- 所有 Bot 共享登录与文件；用 Agent Mail 做身份隔离  
- Update Computer 会重建 OS 镜像，apt 软件要重装  
- 模板导出曾有 `skills: []` bug  
- 登录算一台 Cursor 设备，可能撞设备上限  
- 案例金额、CCU、省钱数字多为**作者自述**，不作保证  

## 适合谁

- 要养「AI 同事」而不是多问两句聊天的人  
- 想抄中文橙皮书 + 全球案例库的 Grok Bot 用户  
- 正在编 Grokbot 应用修炼 / 幕僚长编制的人
