## 一句话定位

七鹿AI 用「做了几十个 Roblox 游戏站」的实践结论：真正难的不是建站（AI/Codex 已解决大半），而是**选游戏**——追已爆热点往往既晚又卷；应在爆发前抓早期信号，把「数据型 / 可查询对象多」的游戏建成知识库式 SEO 站。文末预告选词系列第二篇，并引流交流群；系列整体服务 **RB Auto** 全自动 SEO 流量站矩阵卖点。

## 上手顺序

1. **先认清体裁**：方法反思帖 + 系列开篇，不是逐步建站教程；RB Auto / 批量上站是产品与工具背景。
2. **对齐痛点**：是否也在「游戏火了 → 查趋势 → 买域名上站 → 等流量」，结果半月无热度或域名被占光？
3. **改第一性提问**：不问「现在多少 CCU」，问增长楼梯、内容密度、传播属性。
4. **只做「数据型游戏」**：不断新增可查询对象（宠/装/角/交易价值），玩家会自然搜 codes / wiki / tier / value / calculator。
5. **调流程**：早期游戏 → 爆发信号 → 提前上站 → 日常更新等搜索外溢；别等趋势陡峭再冲。
6. **系列往下读**：Ep2 共性特征信号；Ep3 可量化五指标 + 开源评估 Skill。

## 可复制点

1. **三问选游戏**：有无增长趋势（楼梯）？有无内容密度？有无传播属性（短视频钩子）？
2. **反例口诀**：高 CCU + 无脑单动作 / 只出 codes → Google 几乎无外溢 → 不适合长期独立站。
3. **流程对照**：旧=追热门趋势上站；新=挖早期信号提前布局。
4. **系列导航**：本篇=为什么选游戏；下篇=100 款共性；再下=指标化。
5. **联系**：文中 VX `aiqizilu`（群/交流，以文为准）。

## 坑

- 「玩家多」≠「可做 SEO 站」；缺信息结构就缺搜索问题。
- 趋势陡峭时入场=新手新站打固化首页，性价比差。
- 营销造势尖峰易被误读为爆款楼梯。
- 本文不给具体阈值公式或开源仓（那是 Ep3）；不要当成可照抄的选股公式。
- 产品/群/过审话术是引流；方法骨架可抄，承诺数字不可当实测。

## 适合谁

- 做 Roblox / 游戏 SEO 站、已会或计划用 AI 批量建站、卡在「选哪个游戏」的人。
