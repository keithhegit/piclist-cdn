## 开场：目标与难点

- 挑战：只用嘴（自然语言），把闲置旧电脑改造成家庭 AI 服务器——配置 Agent 环境、部署本地模型、再跑一套前后端 AI 服务；不手动折腾、不查教程，让 AI 自己完成配置。
- 难点：多数 AI Agent **写代码强**，但一到 **系统环境搭建** 就容易卡住——缺少操作系统层级的权限与理解。
- 工具选择：腾讯 **Marvis（马维斯）**——操作系统层级的个人 AI 助手；自带多个专家 Agent，其中 **Computer Agent** 可接管 OS 级操作（「住在操作系统里面」）。

## 从零：只装 Marvis 的 Windows 旧机

- 旧机装熟悉的 Windows；电脑上起初 **只安装 Marvis**，从零开始。
- 小测：桌面没有「此电脑」图标 → 口令大意：「把『此电脑』图标弄到桌面上」。
- 演示结果（作者声称）：Marvis 改注册表并重启 Explorer，约 **10 秒**完成；对比手动路径：设置 → 个性化 → 主题 → 桌面图标设置。

## 家庭服务器基础：暂停更新、关广告

- **暂停 Windows 更新**（求稳、少重启）：Marvis 先给出系统自带「最多暂停 4 周」；作者继续要求搜注册表方案暂停更久（口播称 **9999 周**），由 Computer Agent 改完并给出设置入口（作者演示）。
- **关闭 Windows 自带广告**：口令大意「关闭 Windows 上的广告」；作者称不到一分钟关了多项系统广告，个别任务栏推送需手动点 Marvis 给出的入口。

## 效率模式 vs 本地模式

- 前述对话在 **端云协同的「效率模式」** 下完成；作者称设备越好越省 token。
- 配置够高可切 **本地模式**：本地模型对话/处理，数据不出本机，强调隐私。

## 开发三件套 + Claude Code

- 口令大意：「帮我安装 Git、Node.js、还有 Python」→ 同时打开安装窗，点下一步；再让 Marvis 用命令行确认安装成功。
- 再装 AI 编程工具：**Claude Code**；启动命令口播为 `claude`。
- 踩坑：PowerShell **脚本权限**报错 → 把错误贴给 Marvis 修复后可启动（作者称观众常踩此坑）。

## 本地模型：读硬件 → 选型 → Ollama

- 口令大意：「我想在本地部署一个 AI 模型，你查一下这台电脑的配置怎么样。」
- 画面核对（关键帧）：硬件清单示例为 **ASUS TUF Gaming A15**、Ryzen 7 6800H、**16GB**、**RTX 3060 6GB**、Win11；作者称关键限制在 **6GB 显存**。
- 需求：模型要有 **多模态**（图像识别）→ Marvis 联网搜索后推荐开源 **千问 3.5 4B** 类型号，用 **Ollama** 部署；并称不必单独装 CUDA。
- 演示：自动装 Ollama、拉起模型、发测试句通过（作者声称）。

## 实战应用：本地卡路里 APP（后端 + PWA）

- 动机：拍照识别食物卡路里并记账；不想让别人知道吃了啥 → **完全本地模型**。
- 后端：上传图片、识别、写本地库；推理走本机 Ollama；Marvis 侧口播称接入 **DeepSeek** 辅助编程，交付后端代码。
- 测试：装 **Postman**；`form-data` 上传测图 → 200 OK，画面示例识别「鱼香茄子 / 350 卡」并入库（演示数据）。
- 前端：**React PWA**，手机拍照发给后端。
- 局域网访问：让 Marvis 查家庭网络拓扑；口播示例本机 IP **192.168.31.145**，手机浏览器打开后可用（演示环境地址，勿照抄）。

## 离家访问与语义找文件

- 传统内网穿透：繁琐且不稳（作者观点）。
- Marvis：手机装 App 扫码连家中电脑 → 对话 + **实时桌面** + 键鼠接管。
- 示例口令：「帮我找一下家里的房屋平面图」→ 可按文件名/内容/ **图片内容** 检索；即使文件名无关（如日期命名 PNG）也能凭画面定位并传到手机。

## 收束

- 对比普通聊天机器人：不只「告诉你怎么做」，而是能进电脑做 OS 级操作。
- 价值：吃灰旧机重新变成可持续创造价值的生产力工具；电脑更「听得懂人话」。
