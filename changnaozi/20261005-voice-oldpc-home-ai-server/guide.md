## 一句话定位

不手搓环境：在几乎空的 Windows 旧机上只装腾讯 **Marvis**，用自然语言完成系统调优、装 Git/Node/Python 与 Claude Code、Ollama+多模态本地模型，并落地「拍照记卡路里」前后端，再用手机 App 远控与按图片语义找文件。

## 上手顺序（据视频演示整理）

1. **选机与装系统**：闲置 Windows 机；先只装 Marvis（官网分 Win/Mac/手机端）。  
2. **小任务验证 OS 能力**：如桌面「此电脑」图标、暂停更新、关系统广告（注意注册表/更新策略风险，见坑）。  
3. **认清双模式**：效率模式（端云协同，省本地算力）；本地模式（端侧模型，数据不出机）——官网门槛约 ≥4 核 / 8GB / SSD（隐私模式通常要更高）。  
4. **装开发三件套**：口令装 Git + Node.js + Python，再装 Claude Code；修 PowerShell 执行策略类报错。  
5. **读硬件 → 选型 → Ollama**：让 Marvis 读 CPU/内存/显存；按显存选多模态小模型（演示为千问 3.5 4B 量级 + Ollama）。  
6. **做一个本地 AI 应用**：如图片→结构化结果→本地库；Postman 测 API；React PWA + 局域网 IP 访问。  
7. **手机远控**：Marvis App 扫码绑定，对话 + 看桌面；用语义/多模态搜本地文件，少依赖内网穿透。

## 坑 / 注意

- **视频号无法直接拉流**：本环境只能拿元数据+封面；正文依据 B 站同题成片，属「成片替代」而非微信原始文件。  
- **ASR 非逐字稿**：已校常见错识，专有名词仍可能偏差；以画面字幕/官方文档为准。  
- **改注册表 / 停更新 / 关广告**：有安全与合规风险；「9999 周」等为演示说法，生产环境慎用。  
- **演示硬件 ≠ 你的旧电脑**：画面为带 RTX 3060 的游戏本；真·低配闲置机可能跑不动同档本地多模态。  
- **局域网 IP、卡路里数字、模型名**：演示现场值，勿当通用配置。  
- **Claude Code / Ollama / 权限策略**：各工具版本变化快；报错粘贴给 Agent 修复的思路可迁移，步骤需自查官网。  
- **隐私**：效率模式会走云端；敏感数据用本地模式并审权限（文件/屏幕/系统）。  
- **产品定位**：Marvis 是腾讯 OS 级「AI 管家」；视频是创作者评测向教程，不是腾讯官方安装手册。
