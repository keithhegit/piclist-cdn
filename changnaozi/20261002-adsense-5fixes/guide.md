# AdSense 过审五要素与收款路径 - 微信

## 一句话定位
工具站/SEO 流量站申请 Google AdSense 时，审核看的是「像不像正经项目」（About/Contact/Privacy + 实打实内容），不是文章堆量；补齐五要素后作者三天过审。

## 上手顺序（对照三站 SEO 站）
1. 先配齐 **About / Contact / Privacy**，底部导航可点；Privacy 用 TermsFeed/iubenda 生成后替换公司名与邮箱占位符。
2. 维持 **8–15 篇**能回答具体问题的实文（有结构、有例子、少套话）；避免同一天批量发。
3. 确认 **HTTPS + 移动端**（PageSpeed 红色警告修掉）；申请期 **先卸竞品广告**。
4. 用 **.com/.net/.org** 等顶级域名，少用免费二级域。
5. 再点申请：税务（大陆个人常用 W-8 BEN）→ 放广告代码等审 → 收益门槛后身份验证 → PIN 平信 → 电汇收款（满 $100）。

## 能力表
| 项 | 要做什么 | 为什么 |
|---|---|---|
| 三页合规 | About / Contact / Privacy | 作者称 2025 Q2「内容不足/可信度」拒审中约 79% 缺信息架构（文中数据，非官方一手） |
| 内容 | 8–15 篇实文，自然节奏 | 「内容不足」常被误解成「再写更多」 |
| HTTPS+移动 | 必开；修红警 | 底线 |
| 独占广告 | 审期间拿掉别家广告 | 降低竞品干扰 |
| 域名 | 顶级域 | 免费二级通过率更低（作者经验） |

## 金句 / 可复用口径
- 「审核不看你写了多少篇，看你的网站像不像一个正经项目。」
- 「问题根本不在文章数量。」
- 「一次过的概率远大于攒够 50 篇再申。」（作者主张）

## 坑
- 把「内容不足」理解成「再堆 10 篇」→ 继续拒。
- Privacy 占位符未替换 / 底部找不到。
- 一天发一堆文；申请期还挂别家广告。
- 账号姓名与证件不一致 → 身份验证卡住。
- 被拒后立刻连申；作者建议改完至少等一周，一个月内拒三次不好看。
- **文中 AdSense 拒审比例等数字是作者引用口径，入库/对客勿当 Google 官方声明。**

## 适合谁
正在或准备给 Roblox Map SEO / 工具站接 AdSense 的人；与当前三站「广告等 ca-pub」直接相关。
