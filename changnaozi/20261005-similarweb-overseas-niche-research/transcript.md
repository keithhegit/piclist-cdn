## 导语

- 多数人只用 SimilarWeb（similarweb.com）查月访问量就关掉——作者比喻为「买了一台显微镜当镇纸用」。
- 真正值钱的不是「这个站有多少流量」，而是回答：**这个赛道值不值得做，能不能赚钱**。
- 作者主张：建站前花 **30 分钟** 做 SimilarWeb 调研，比建完才发现选错赛道「至少值几个月」。

## 一、大多数人用 SimilarWeb 的方式是错的

- 常见误用：看到竞品月访 50 万就开工——「用数据给自己壮胆，不叫调研」。
- 作者认为流量数字是「最不重要的数据」，原因：
  - 估算值，建议「打个 7-8 折看」才靠谱（作者说法）
  - 流量大 ≠ 你能分到份额，要看竞争格局
  - 流量大 ≠ 能赚钱；工具站与内容站变现方式不同
- 真正该看：**流量从哪来、靠什么词、导去哪里、谁在涨谁在跌**。

## 二、五个被忽略的功能

### 功能一：流量来源拆解

- 渠道（作者列出 6 类）：直接访问、自然搜索、付费搜索、外链引荐、社交、**生成式 AI**。
- 解读示例：
  - 自然搜索约 70% → 靠 SEO，要做同类关键词
  - 社交约 60% → 增长靠 Pinterest / TikTok 等，纯 SEO 可能跟不上
  - 直接访问 ≥50% → 工具站典型，有品牌认知、不主要靠搜索
  - 2026 年新增生成式 AI 渠道：若竞品已从 ChatGPT、Perplexity 拿量而你没有，说明 **GEO（AI 搜索优化）** 已落后
- 用法：看「流量来源」饼图，对比 3–5 个竞品的渠道结构，决定重点投入哪个渠道。

### 功能二：关键词差距（Keyword Gap）

- 免费版约能看每个站排名前 **5** 个自然词；付费版看全部（作者说法）。
- 比「看竞品有哪些词」更有用的是 Keyword Gap / 韦恩图：重叠区、**机会区**（竞品有你没有）、你的优势区。
- 机会区 = 接下来该写的内容；竞品已验证有需求。
- 站未建时：输入 3–4 个同赛道竞品，看共同排名词 → 内容路线图。

### 功能三：出站流量（Outgoing Traffic）——推断变现

- 看访客离开后去向，反向推断变现：
  - Amazon（带 affiliate）→ 亚马逊联盟
  - Bluehost / Hostinger → 主机联盟
  - ClickBank → 数字产品
  - YouTube → 大量嵌视频
- 用法：找「出站流量 / 热门链接目的地」，作为同赛道变现参考。

### 功能四：相似网站 / 「受众也访问了」

- 用途重点不是堆更多竞品，而是发现**相邻赛道**。
- 例：咖啡器具评测站受众还大量访问居家装修、手工艺 DIY → 可延伸「咖啡角布置」「手冲仪式感」。

### 功能五：流量趋势对比

- 免费版约看 **3 个月**，付费更久（作者说法）。
- 单站曲线意义有限；要把同赛道 3–5 站一起比：
  - 整体涨 → 上升期
  - 整体跌 → 慎入
  - 大站跌、小站涨 → 碎片化，小站有机会
  - 某站陡升 → 研究那段时间它发了什么、做了什么
- 「斜率比绝对数值重要得多」。

## 三、30 分钟赛道评估流程

| 时段 | 做什么 |
|---|---|
| 1–5 分钟 | 看头部 1–2 站月访量级；若头部不到约 **1 万**/月，作者认为需求可能太小，要谨慎 |
| 5–15 分钟 | 流量来源：自然高→SEO 空间；社交高→内容营销；直接高→工具属性 |
| 15–20 分钟 | 出站流量 → 变现路径 |
| 20–25 分钟 | 相似网站 / 相邻赛道 |
| 25–30 分钟 | 3–5 站趋势对比 |

- 结束后应能答三问：**有没有需求？需求从哪来？能不能变现？**

## 四、免费版够不够用

- 作者认为个人站长用免费版（网页 + Chrome 插件）**基本够用**，可见：月访与约 3 个月趋势、渠道占比、地理分布、前 5 自然词、出站目的地、相似网站。
- 免费看不到：完整关键词列表、难度分、>3 个月历史、CSV 导出。
- 付费：Pro 起步约 **125 美元/月**（作者说法）。
- 建议：免费版看趋势与渠道结构 + **Google Search Console** 看自己站真实关键词，互补。

## 五、重要提醒：数据是估算的

- 来源：插件采样、ISP、公开爬虫 + 算法推算。
- 作者提醒：
  - 流量越大越准；约 **10 万+**/月较可靠
  - 约 **5,000** 以下可能严重偏差甚至查不到
  - **中国境内站**数据严重失真（插件覆盖低）
  - 趋势方向比绝对值可靠；具体数字建议打 **7–8 折**
- 「不要拿它的数字当精确值引用，更不要拿它来做投资决策的唯一依据。」

## 六、行动清单

1. 装 SimilarWeb Chrome 插件（免费）
2. 找出赛道 3 个头部竞品，跑一遍 30 分钟流程
3. 记下竞品出站流量最大的 3 个目的地 → 变现参考

- 收束句：「SimilarWeb不是帮你看到数字的工具，是帮你看到机会的工具。」
