## 一句话定位

「放过自己」不是躺平、也不是「算了什么都无所谓」，而是：**生活已经很难的时候，别再拿最后一点能量继续攻击自己**——先允许不完美、不被所有人喜欢、会嫉妒、会停摆、会放下「我本来应该成为谁」，再谈继续往前走。

## 适合谁

- 长期自我攻击、反刍「我还不够好」、把人生当成只能向上的进度条的人  
- 刚经历挫折/分手/失业，知道「不该这样」却停不下来自责的人  
- 短视频选题：自我慈悲 / 内耗 / 允许 / 反完美主义 / 和自己和解

## 上手顺序（建议 7 天，只做上集 1–5）

1. **今天改定义**：把「放过自己＝摆烂」改成「停止自我攻击＝把能量留给还能动的事」。  
2. **本周只练一条「允许」**（对应上集整理）：  
   1. **允许有些事做不好**：像对待受挫的朋友一样对自己；60 分仍可以是个很好的人。  
   2. **允许别人不喜欢你**：别人怎么看你，不全由你是谁决定，也取决于对方是谁；把精力收回自己的事。  
   3. **允许自己嫉妒**：先问羡慕的是钱、自由、认同、工作还是生活状态——嫉妒当信息，不当罪名。  
   4. **允许偶尔什么都不想做**：出去走走、发呆、喝杯咖啡；停摆≠人格失败。  
   5. **放下「我本来应该成为谁」**：写下「现在的我 / 想成为的我 / 应该成为的我」；追问「应该」是谁给的、你是否还想要。  
3. **验收**：不做人生大翻盘；只看「自责时长是否下降 + 是否完成 1 次对自己的朋友式对话」。  
4. **想听全 10 条**：续看下集 / 小宇宙 EP30（约 39 分钟合集），再练 6–10（选错、别人的进度条、无答案、人生不必一直向上、放过「必须一直更好」的执念）。

## 能力表 / 核心论点（上集为主）

| 论点 | 可操作含义 |
|---|---|
| 放过 ≠ 放弃努力 | 难的时候先停火，不当自己最严的审判者 |
| 允许做不好 | 承认边界；用「足够好」换「完美」 |
| 允许不被喜欢 | 课题分离：他人评价不全是你的 KPI |
| 嫉妒可被允许 | 先命名羡慕对象，再决定要不要追 |
| 允许停摆 | 休息是资源管理，不是道德瑕疵 |
| 放下「应该成为」 | 区分外部剧本与自己真正还想要的 |

## 完整十点清单（结构校对；非 ASR）

> 来源：小宇宙 EP30 评论清单 × 抖音上集「作者赞过」1–5 操作化评论。上集视频大致覆盖 **1–5**；**6–10** 多见于下集 / 播客后半。

1. 允许自己有些事情就是做不好（承认边界）  
2. 允许别人不喜欢你  
3. 允许自己嫉妒别人  
4. 允许自己偶尔什么都不想做  
5. 放弃「我本来就应该成为谁」的念头  
6. 接受：有些选择就是选错的  
7. 别用别人的进度条来衡量自己  
8. 允许一些问题没有答案  
9. 接受人生不会一直向上  
10. 放过那个一直想把自己变得更好的人（接受现在的自己，才开始能改变）
