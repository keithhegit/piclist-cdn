## 一句话定位

「放过自己」不是躺平、也不是「算了什么都无所谓」，而是：**生活已经很难的时候，别再拿最后一点能量继续攻击自己**——从允许不完美，到接受人生不必一直向上，再到先接纳现在的自己，才谈得上真正改得动。

## 完整十点（1–10）

> **主交付**。1–5：Keith 校对口径。6–10：下集 / 小宇宙 EP30 评论交叉（非 ASR）。

1. **允许自己有些事做不好** — 像对待正在经历挫折的朋友一样对待自己。
2. **允许别人不喜欢自己** — 把精力放在属于自己的事情上，不去控制那些本不属于自己的；别人怎么看我那是别人的事，与我无关。
3. **允许自己嫉妒别人** — 问自己到底羡慕别人什么：钱、自由、认同感、工作，还是羡慕别人的生活状态。
4. **允许自己偶尔什么都不想做** — 出去走走，发会儿呆，或者喝杯咖啡。
5. **放弃「我本来应该成为谁」的念头** — 想一下：现在的我 / 想成为的我 / 觉得自己应该成为的我。问自己①所谓的「应该」是谁告诉自己的②自己是不是还想成为那样的人。
6. **接受有些选择就是选错的** — 选错了就承认，别反复用「当时要是……」惩罚自己；改下一步，而不是改历史。
7. **别用别人的进度条衡量自己** — 别人的职位、收入、成家节奏是别人的赛道；只盯自己下一小步，不拿别人的里程碑当 KPI。
8. **允许一些问题没有答案** — 关系、命运、为什么是我——有些题本来就解不开；先学会带着问题生活，而不是逼自己立刻给结论。
9. **接受人生不会一直向上** — 工作、收入、感情不必一年比一年更好；可以「四处走走、随便走走」，低谷不等于人生判负。
10. **放过那个一直想把自己变得更好的人** — 先接受「现在的我也还不错」，再谈好奇往后会成为怎样的人；接受自己，才开始改得动。

## 适合谁

- 长期自我攻击、反刍「我还不够好」、把人生当成只能向上的进度条的人  
- 刚经历挫折/分手/失业，知道「不该这样」却停不下来自责的人  
- 短视频选题：自我慈悲 / 内耗 / 允许 / 反完美主义 / 和自己和解

## 上手顺序（建议 10 天，一天一条）

1. **今天改定义**：把「放过自己＝摆烂」改成「停止自我攻击＝把能量留给还能动的事」。  
2. **按序练 1–10**：每天只练一条；写一句「今天我允许/接受了什么」。  
3. **验收**：不做人生大翻盘；只看「自责时长是否下降 + 是否完成 1 次对自己的朋友式对话 + 是否少拿别人进度条当 KPI」。

## 能力表 / 核心论点

| 论点 | 可操作含义 |
|---|---|
| 放过 ≠ 放弃努力 | 难的时候先停火，不当自己最严的审判者 |
| 允许做不好 | 承认边界；用朋友式语气对自己 |
| 允许不被喜欢 | 课题分离：他人评价不全是你的 KPI |
| 嫉妒可被允许 | 先命名羡慕对象，再决定要不要追 |
| 允许停摆 | 休息是资源管理，不是道德瑕疵 |
| 放下「应该成为」 | 区分外部剧本与自己真正还想要的 |
| 选错可承认 | 改下一步，不改历史 |
| 进度条自有 | 别人的里程碑不是你的 KPI |
| 无答案可带着走 | 先带着问题生活，再逼结论 |
| 人生可横着走 | 低谷 ≠ 判负；可四处走走 |
| 先接受再改变 | 「现在的我也还不错」才改得动 |
