## 这本书在干什么

- 标语（作者）：「用最少的钱、时间、精力和毅力，换回最多的寿命、金钱、时间和人身自由。」
- 每条写清：**成本、收益、证据等级、原始出处**；来源优先期刊论文与官方文件。
- 收益按受益人分档：自己 → 配偶直系亲属 → 朋友同事 → 陌生人（档越低，回报期望越小、风险要写清）。
- 用法：是**按性价比排好的备选单，不是任务清单**；「作者自己也没做到其中大部分」。
- 另有在线筛选、PDF/EPUB/离线 HTML、AI skill（Claude Code / Codex：先查书再答并标注出处）。
- 声明：项目**从未/不会发行代币**；冒用发币视为骗局。

## 证据与性价比（作者框架）

| 证据 | 含义（作者） |
|---|---|
| A | 有具体数字；荟萃/大型队列/RCT 等，或法律政策类引到法条原文 |
| B | 有研究但数字弱，或小样本/单篇 |
| C | 经验或公认做法，无直接文献 |
| 性价比 | 作者判断（自称按本书标准也只算 C 级）：结合收益量级与花钱/时间/毅力 |

## 34 节目录与要点（各一两句）

1. **不要早死** — 交通/火灾燃气/溺水跌倒、硬证据疫苗与筛查、心理危机与家庭应急；例：安全带、烟雾报警器、HPV、血压（多 A 级文献）。
2. **不要慢慢死** — 烟酒、运动、睡眠、饮食（低钠盐等）、久坐与戒烟戒酒具体办法。
3. **不要浪费精力** — 睡眠、打断、多任务、人际负债、与机构打交道的预期。
4. **不要浪费时间** — 沉没成本、拖延、会议、通勤。
5. **不要浪费钱** — 订阅、彩票、利率、保险、基金费率、公积金/医保账户、车险、直播带货、虚拟货币等；投资条目声明「不构成投资建议」。
6. **反面清单** — 看起来划算其实不划算的东西（保健品/体检套路等）。
7. **没钱的时候怎么活** — 失业金、仲裁、救助、低保、医保、求职避坑。
8. **别把自己搭进去** — 交通事故、止付、彩礼婚前财产、担保、反诈、失信、养犬等法律与财产安全。
9. **普通人容易踩的法律红线** — 谣言、洗钱兼职、骗贷、高空抛物、偷拍、赌博、野味等。
10. **恋爱和结婚划不划算** — 择偶、纠缠红线、登记婚检、健康/时间/钱账与退出成本。
11. **程序员和技术人容易踩的红线** — 外挂、爬虫、抢票脚本、删库、带走源码、竞业、开源许可、备案、AI 中转站等（法条 + 判例数字）。
12. **创业与做生意** — 本钱、担保、主体、许可、纳税、发票、合同、用人、退场与创业骗局。
13. **紧急情况** — 心脏骤停、大出血、过敏、火灾溺水、中毒、蛇咬地震等先做什么；含「救不救得起」自保边界。
14. **账号与信息安全** — 2FA、密码、SIM、丢机、权限、人脸、查阅删除权。
15. **租房与买房** — 押金、腾退、资金监管、买卖不破租赁、隔断房、宅基地红线。
16. **得了慢性病之后怎么活** — 依从用药、门诊慢特病跨省、复查、长期处方、并发症筛查。
17. **家里有老人** — 意定监护、遗嘱、骗局、长护险、压疮与白内障。
18. **养孩子划不划算** — 补贴、产假生育津贴、时间账与钱账。
19. **在职、离职和工伤** — 加班年休试用、职业病防护、N/代通知金/2N、工伤认定与工亡。
20. **刚出生的孩子怎么带** — 安全睡眠、乙肝首针、母乳辅食、发热红线等。
21. **出国、旅行与境外安全** — 安全提醒、12308、领事边界、境外医保与骗局、驾照。
22. **怎么放松** — 娱乐场所安全与涉毒红线；运动正念呼吸社交绿地。
23. **学什么技能划算** — 教育回报、山寨证、培训补贴、抗自动化、技能等级与怎么学。
24. **看病：怎么少花钱少走弯路** — 分级诊疗、起付线、异地就医、急诊分诊、种植牙包干价等。
25. **人走了以后要办什么** — 死亡证明、火化、户口、殡葬清单、公积金社保、死者信息权。
26. **做一个网站或平台** — 支付/二清红线、ICP 许可与备案、直播视听资质、平台核验涉税、内容治理、实名、未成年人、通知删除、数据出境、服务器选型（对建站/平台合规极相关）。
27. **怀孕和生产** — 叶酸建册、筛查阻断、就医信号、生育保险、出生证明与落户。
28. **别为了外形把身体搞坏** — 极端节食、医美资质、减肥药激素、正畸复诊等。
29. **遭遇重大打击之后** — 丧亲/重病/失业窗口期、12356、别在应激期做不可逆决定。
30. **上学以后的孩子** — 急症、欺凌、户外、近视抑郁筛查、睡眠作业、休学等。
31. **十八岁之后有哪几条路** — 当兵、特岗、文职、自考成考、公费定向、出国打工、灵活就业社保等门槛。
32. **出国留学** — 认证院校、签证身份、打工时数、保险、留服认证。
33. **残疾之后怎么活** — 并发症、自杀窗口、办证待遇、康复、就业残保金、监护等。
34. **家里的常备药别吃出事** — 对乙酰氨基酚重复、儿童退烧禁忌、感冒不滥用抗生素等。

## 抽样阅读印象（非全书）

- **条目模板固定**：成本 → 说人话 → 收益（可含 HR/RR）→ 证据等级 → 来源（DOI/法条）→ 备注（争议/适用人群）。
- **第 1 节**：意外与筛查并重，大量 A 级公共卫生文献，并标明观察性 vs RCT。
- **第 5 节**：个人理财与消费陷阱，多项引财政部/央行/证监会口径，并反复写「不构成投资建议」。
- **第 11 节**：技术人刑事/民事红线，用最高检最高法案例与法条数字说话。
- **第 26 节**：平台支付、ICP、直播资质、实名、未成年人、数据出境——直接服务「做网站/做平台」合规。
