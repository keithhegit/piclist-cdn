## Level 1 · 刚打开 AI 工具就会遇到的词（15）

1. **AI** · 人工智能：让机器完成过去需要人类智力才能做的任务（写作、识图、编码等），目前强在局部任务，不等于具备完整人类思维。
2. **聊天框**（Chat）：输入文字、返回回答的对话式 AI 入口；只负责对话，区别于能动手执行任务的 Agent。
3. **输入 / 输出**（Input / Output）：交给 AI 的问题、材料、要求是输入；AI 返回的文本、图片、代码等是输出，输出质量高度依赖输入质量。
4. **联网搜索**（Web Search）：让模型实时检索网络信息，弥补其训练知识的时间截止，适用于新闻、价格、版本等时效内容。
5. **对话历史 / 记忆**（History / Memory）：同一窗口内模型参考前文即对话历史；跨窗口记住用户需产品提供长期记忆功能。
6. **Prompt** · 提示词：交给 AI 的任务指令，好的 Prompt 写清对象、目标、口吻、格式与禁忌。
7. **模型**（Model）：AI 背后实际进行理解与生成的核心程序，可理解为 AI 的"大脑"。
8. **模型版本**（Model Version）：同一模型系列的迭代版本，升级通常带来能力、速度、价格或上下文长度变化。
9. **模型类型**：按处理对象划分的文字、图像、视频、语音、多模态等模型；复杂任务常由多种模型配合完成。
10. **AIGC** · AI 生成内容：主要由 AI 生成的文章、图片、音视频、代码等内容。
11. **AI 应用**（AI App）：把模型能力包装成普通人可直接使用的产品；模型是发动机，应用是整车。
12. **上下文**（Context）：当前对话中模型能看到的全部前后内容。
13. **知识库**（Knowledge Base）：预先上传的固定资料，让 AI 依据这些资料回答（制度、课程、客服话术等）。
14. **插件**（Plugin）：给 AI 额外接入的能力模块，如搜索、运行代码、读表格、生成图片。
15. **多模态**（Multimodal）：模型能同时理解和处理文字、图片、语音、视频等多种信息。

## Level 2 · 稳定使用 AI 必须懂的词（12）

16. **LLM** · 大语言模型（Large Language Model）：在海量文本上训练、擅长理解与生成语言的模型，聊天式 AI 多属此类。
17. **开源模型 / 闭源模型**（Open / Closed Source）：开源模型权重可下载、修改、本地部署；闭源模型只能通过官方产品或 API 使用。
18. **AI 幻觉**（Hallucination）：模型把无依据或错误的内容说得像真的一样，重要信息必须核验。
19. **System Prompt** · 系统提示词：开发者预设的、规定 AI 身份、边界与行为规则的指令，优先级通常高于用户指令。
20. **Temperature** · 温度：控制输出随机/发散程度的参数，高则更有创意但不稳定，低则更保守严谨。
21. **Token** · 词元：模型处理与计费的基本单位，文字（及图片、音频）都会被切分折算成 Token。
22. **上下文窗口**（Context Window）：模型单次能处理的最大 Token 数，超出部分会被截断或遗忘。
23. **Markdown**：用 `#`、`-`、`**` 等简单符号表示结构的轻量文本格式，便于 AI 读写和保存结构化内容。
24. **提示词工程**（Prompt Engineering）：研究如何组织指令、示例和约束，让模型输出更准确稳定的方法。
25. **RAG** · 检索增强生成（Retrieval-Augmented Generation）：先从外部资料检索相关内容，再让模型基于检索结果生成回答。
26. **Embedding** · 向量嵌入：把文字等内容转换成一串数字向量，使计算机能按语义相近程度比较内容。
27. **向量数据库**（Vector Database）：专门存储和按语义相似度检索 Embedding 的数据库，常作 RAG 的底座。

## Level 3 · 从聊天走向自动化（13）

28. **AGI** · 通用人工智能（Artificial General Intelligence）：在大多数领域达到或接近人类水平的智能系统，仍是行业长期目标。
29. **涌现**（Emergence）：模型规模、数据或训练达到一定程度后，突然出现未被专门训练过的新能力。
30. **深度思考**（Deep Thinking / Reasoning Mode）：模型花更多时间和 Token 先思考再作答的模式，更慢但更适合复杂问题。
31. **推理**（Reasoning）：模型一步步分析、推导问题的能力，决定数学、逻辑、排错等任务的可靠性。
32. **To C / To B**：To C 面向个人消费者，To B 面向企业客户，描述产品的服务对象与商业模式。
33. **AI Native** · AI 原生：从设计之初就以 AI 能力为核心构建的产品，而非在旧软件上加聊天框。
34. **Agent** · 智能体：能自主拆解任务、调用工具、读写文件、运行代码并完成多步目标的 AI 系统。
35. **工作流**（Workflow）：把多步任务按固定顺序串联成可重复执行的流程，是自动化的基础。
36. **Vibe Coding** · 氛围编程：用自然语言描述需求、让 AI 写代码，人负责验收和迭代的开发方式，仍需测试与调试。
37. **API / API Key** · 应用程序接口 / 密钥：API 是软件之间互相调用能力的接口；API Key 是调用凭证，等同密码，不可外泄。
38. **报错 / Debug**（Error / 调试）：报错是程序给出的异常信息；Debug 是依据报错、日志定位并修复问题的过程。
39. **工具调用**（Tool Use / Function Calling）：模型自行决定何时调用外部函数或工具（查库、搜网、执行脚本）并使用其结果。
40. **模型评测**（Evaluation / Benchmark）：用标准任务集比较模型在写作、推理、代码等方面表现的方法，榜单仅供参考。

## Level 4 · AI 工程开发（5）

41. **GitHub**：基于 Git 的代码托管与协作平台，大量开源 AI 项目、模板和插件发布于此。
42. **前端 / 后端**（Frontend / Backend）：前端是用户可见的界面与交互；后端是看不见的数据存储、接口、业务逻辑与安全校验。
43. **Skill / MCP**：Skill 是封装好的专用能力包（如做 PPT、处理表格）；MCP（Model Context Protocol，模型上下文协议）是让 AI 以统一方式接入外部工具和数据源的开放协议。
44. **微调**（Fine-tuning）：在已有模型基础上用特定领域或任务数据继续训练，使其更贴合业务。
45. **训练**（Training）：用大量数据调整模型参数、让其学习规律的过程，完整训练大模型成本极高。

## Level 5 · 部署与运维（7）

46. **Terminal** · 终端：通过输入命令与电脑交互的文本窗口。
47. **命令**（Command）：在终端中输入、让电脑执行某个动作的语句，如安装依赖、启动服务。
48. **路径**（Path）：文件或文件夹在电脑中的位置地址，写错会导致"找不到文件"。
49. **环境变量**（Environment Variable）：存放在系统运行环境中的配置值（如 API Key、数据库地址），避免把密钥写进代码。
50. **服务器 / 部署**（Server / Deploy）：服务器是远程运行程序的计算机；部署是把本地做好的程序放到服务器上供他人访问。
51. **私有化部署**（On-premise / Private Deployment）：把模型或 AI 系统部署在自有服务器、内网或本地，满足数据安全与合规要求。
52. **推理成本**（Inference Cost）：模型每次实际生成回答所消耗的算力与 Token 费用，模型越大、上下文越长越贵。

## Level 6 · 底层模型原理（5）

53. **神经网络**（Neural Network）：受人脑神经元连接启发、由多层可调节节点组成的算法结构，是大模型的基础。
54. **参数**（Parameters）：模型内部通过训练学到的可调数值，数量常用于衡量模型规模，但多不等于更适合你的任务。
55. **AI 三要素**：算法、数据、算力——算法决定怎么学，数据决定学什么，算力决定学不学得动。
56. **预训练 / 后训练**（Pre-training / Post-training）：预训练是在海量数据上的大规模通识学习；后训练（如指令微调、人类反馈强化学习）让模型更会对话、更守规则。
57. **模型蒸馏**（Distillation）：用大模型的输出来训练小模型，让小模型以更低成本获得部分能力。

## Level 7 · 硬件与基础设施（3）

58. **CPU / GPU**：CPU 是擅长通用串行任务的中央处理器；GPU 是擅长大规模并行计算的图形处理器，是训练和运行大模型的核心硬件。
59. **算力集群 / 数据中心**（Compute Cluster / Data Center）：大量 GPU 服务器集中组网形成算力集群，所在的机房设施即数据中心。
60. **电力能耗**（Power Consumption）：AI 数据中心训练与推理消耗的大量电力，电力与散热已成 AI 扩张的关键约束。
