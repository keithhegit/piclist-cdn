# 大陆站长 AdSense 收款：PIN + 三条到账路径

> 来源：微信「硅基动力AI」/ 正文署名三木 · [原文](https://mp.weixin.qq.com/s/TuaWNEn_arYQ0ghlSXg1MA) · 2026-09-14 20:00 北京时间 · 约 4.5k 字 · 精要见 `transcript.md`  
> 费率、外汇门槛、税率均为**作者经验主张**，落地以 Google / 银行 / 平台 / 税务机关最新规则为准。

## 一句话定位

给中国大陆出海站长的 AdSense **收款实操选型**：先搞定 PIN 地址验证，再按收入量级在「国内电汇 / 跨境收款平台 / 香港账户」三条路里选，并避开姓名不一致、频繁换卡、退汇封收款等坑。

## 上手顺序

1. **先 PIN**：收入够发 PIN 后盯国际平邮；地址能收信，家人/物业知情；丢了就重寄（作者称最多 3 次）。  
2. **收入还低（作者称月入 ≲ 约 5000 元人民币）**：试国内银行电汇；备好付款截图、服务协议、站点说明。  
3. **收入上来或银行刁难**：开万里汇 / PingPong / 珊瑚 / Payoneer，拿 ACH 绑 AdSense「电汇」；姓名与账户完全一致。  
4. **稳定高收入（作者称月入 ≳ 约 5000 美元）**：再评估香港账户；未到量级不必硬开。  
5. **长期**：少换收款方式；比费率与汇率；税务单独合规，勿依赖文中简化税率表。

## 要点表

| 路径 | 作者主张适用 | 核心动作 | 主要坑 |
|---|---|---|---|
| 国内银行电汇 | 月入较低（≲≈5000 元） | 绑招行/工行/建行等 | 超限额审核、退汇、英文站无备案被拒 |
| 第三方跨境（万里汇等） | 大多数出海站长 | 美账户绑 AdSense → 结汇国内 | 姓名不一致、频繁换卡、汇率差 |
| 香港银行 | 月入较高（≳≈5000 美元） | 赴港开户收美元 | 开户难、维护费、未达量级浪费 |

**平台费率（作者表）**：万里汇 0.3% 封顶 · PingPong 0.4%–0.6% · 珊瑚约 0.5% · Payoneer 约 1%–2%。

## 可复制清单 / 金句

**绑第三方前自检**

```
□ PIN 已验证
□ 平台美元/ACH：Account + Routing 已复制
□ 收款人姓名 = AdSense 账户显示名（一字不差）
□ AdSense → 付款信息 → 电汇 → 提交后等 1–3 工作日验证
□ 不打算短期内再换收款方式
```

**银行要材料时（作者建议备）**

```
□ AdSense「付款历史」截图
□ Google AdSense 服务协议 PDF
□ 域名 + 站点内容一句话说明（证明广告收入来源）
```

**金句（短引）**

- 「不是担心赚不到钱，而是担心赚到了钱收不回来。」
- 「PIN码验证必须完成，否则一分钱也拿不到。」
- 「AdSense收款这件事……PIN码验证、收款方式选择、平台合规性。」
- 「收款，只是这个生意的最后一环。」

## 坑 / 注意

- **非财税/法律意见**：文中税率档、5000 元外汇说法、洗钱风控均为作者概括，可能过时或不完整。  
- **勿违规救收款**：自点广告、流量作弊 → 作者称通常没收余额。  
- **一人一 AdSense**：多账户风险全封；多站应绑同一账户。  
- **平台与银行政策会变**：开户前核对官网费率与到账规则。  
- **站群语境**：作者自述站群经验，合规与关联风险本文未展开，需另看 SEO/站群政策。

## 适合谁

- 做**出海站 / 内容站 / Roblox 攻略站**等、准备或已开通 **AdSense** 的大陆站长。  
- 关心 **SEO 变现闭环最后一环（收款结汇）** 的人。  
- 一般学习跨境收款选型；不适合寻求个性化报税或开户代理承诺者。
