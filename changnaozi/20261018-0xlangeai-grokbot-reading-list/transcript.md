## Article 正文

想了解 Grok Bot，从哪里开始看？

基础用法、IM 接入、额度订阅、内容创作、多 Bot 分工……相关资料散在不同作者的时间线上。看到时觉得有用，过几天再找，往往只记得一个模糊的标题。

我把 24 篇相关文章整理到一起，按主题分成九组，方便大家查找。

刚接触可以从入门部分看起。已经在用了，也可以直接翻到自己感兴趣的分类。

### 一、额度与订阅：看懂新套餐的权益与成本

这一组先看订阅权益、套餐差异和日常额度，具体权益和费用以对应服务的最新说明为准。

**1. 会员与订阅机制对照**  
梳理不同订阅档位的权益和限制，方便比较套餐差异。

**2. 日常使用强度与额度体验**  
从日常任务出发介绍额度消耗，为估算自己的使用需求提供参考。

### 二、入门与认知：从第一名数字员工开始

刚接触 Grok Bot，可以从系统教程和非技术背景的上手方案看起，再按需了解 Bot 创建、Skill、连接器与团队配置。

**3. 万字长文｜Grok Bot 从入门到精通**  
从创建第一名数字员工开始，介绍岗位说明、Skill、定时任务和多 Bot 协作，并用电商案例串起整套流程，适合新手系统了解 Grok Bot。

**4. 非技术背景的上手方案**  
面向不熟悉 API、JSON 和命令行的读者，介绍更容易理解的搭建方式。

**5. 整体认知与进阶路径**  
从基础提问、角色设定到多工具协同，帮助建立一个整体认识。

**6. Grok Bot 零基础入门：创建 Bot、Skill 与连接器**  
从主 Bot、云电脑和 Bot 创建讲起，介绍固定任务、专业领域、CLI 工具与连接器等配置方向，适合刚接触 Grok Bot 的读者。

**7. 从开通到多 AI 协作的完整入门教程**  
梳理界面功能、任务触发、Bot 模板和团队搭建，以内容采集为例介绍分工、交接与审核，并附单个 Bot 和团队配置的访谈提示词。

**8. Grok Bot 入门：安装登录、创建 Bot 与团队搭建**  
从下载安装、账号登录和界面介绍开始，演示创建第一个 Bot、导入模板和组建机器人团队，并介绍常用插件与主要功能。

### 三、接入与跨端：把 Bot 带进微信和飞书

这一组集中介绍微信、飞书等 IM 接入方式，也收录手机和电脑上的快捷调用方法。

**9. 微信接入教程**  
介绍通过消息转发等方式，在微信中调用 Bot 的思路与配置。

**10. Grok Bot 连接飞书，组建一支 X 内容团队，附保姆级教程**  
通过飞书 CLI 和企业应用，组建「X 大总管 + X 情报官 + X 内容官」团队，在飞书群里协作，并把内容整理到飞书文档，适合关注自媒体和内容自动化的读者。

**11. Webhook 与快捷指令**  
围绕 Webhook、API 和 Shortcuts，介绍 iPhone、Mac 上的快捷调用方式。

### 四、云端与服务器：SSH 连接与云环境选型

这一组收录 SSH 远程连接、云电脑配置与选型的资料。

**12. SSH 与远程环境连接**  
关注命令行和远程服务器环境，涉及连接、权限与排错。

**13. 云电脑选型与长期运行**  
从成本、连接情况和维护等方面，介绍云环境的选择思路。

### 五、AI 工具集成：Grok Bot 与外部 AI 协同

这一组关注 Grok Bot 与 Claude Code 等外部 AI 工具的接入，也收录远程调用、环境配置及使用成本说明。

**14. Orca + Tailscale：搭建 Claude Code 云主机**  
在 Grok Bot 云电脑上部署 Claude Code 和 Orca，通过 Tailscale 连接电脑与手机，并介绍环境更新后的恢复、自检和长期运行配置。

**15. Claude Code 额度与消耗机制**  
扩展阅读。讨论 Claude Code 的上下文、缓存与 Token 消耗，适合同时使用这款工具的人。

### 六、角色与分工：主 Bot 统筹与多 Bot 协作

这一组关注主 Bot 怎样统一接收任务，再由专职 Bot 分工、交接和汇总，涵盖日常简报、项目运营等协作方式。

**16. 首席助理与十几个专职 Bot 的协作**  
用首席助理统一接收任务，再分给 X 早报、选题、邮件和项目运营等专职 Bot，分享日常简报、任务交接和人工审核的安排。

### 七、内容与自媒体：从选题调研到写作配图

这一组集中介绍做内容的用法：监控选题、组织自媒体团队、安排调研与写作、调整表达风格，以及整理素材与成稿。

**17. 自媒体多 Bot 内容流水线**  
围绕选题、初稿、润色和多平台转换，介绍多个角色之间的分工。

**18. Grok Bot 内容团队：五层架构与开源 Bot 配置**  
把多 Bot 内容团队拆成总控、判断、输入、增长和生产等层级，介绍文件交接、职责边界与人工验收，并附角色设定和安装入口。

**19. 内容风格与写作约束**  
围绕提示词约束、参考语料和语调调整，介绍内容助手的配置思路。

**20. 用 Grok Bot 搭建 X 爆款监控 Skill**  
围绕对标账号扫描、定时筛选、GitHub 留存和复盘，搭建 X 热门内容监控 Skill，并介绍调用第三方模型处理提交推送的方式。

### 八、编码与工程：开发排错与备份维护

这一组关注 Cursor 等工具的工程协同、代码修改、测试和排错，也收录 Bot 设定与记忆的备份、恢复和迁移方法。

**21. Cursor 与 pstack 协同**  
关注 IDE 与外部 Agent 的配合，适合已经使用相关工具的开发者。

**22. 代码协作与排错流程**  
讨论代码任务中的角色规范、增量修改和测试检查。

**23. Bot 记忆与设定的 Git 备份方案**  
通过「记忆管家」汇总各 Bot 的设定和记忆，保存为 Markdown 并归档到私有 Git 仓库，介绍定时备份、恢复和迁移的做法。

### 九、应用与玩法：跨工具组合与自动化探索

这一组收录 Grok Bot 与其他模型、工具的组合实验，探索常规任务之外的应用思路。

**24. JEV、GrokBot 与 X 发布流程**  
围绕素材整理、内容处理和 X 发布，介绍工具之间的衔接。
