## 上手顺序（建议阅读路径）

1. **先搞清钱和额度（分类一）**  
   统一大订阅后档位多，先看会员对照（#1）和日常额度体验（#2），避免一上来就堆 Bot 把额度烧穿。

2. **建第一名数字员工（分类二）**  
   系统长文优先金尘马《从入门到精通》（#3）；非技术背景走 Kin《非工程师》（#4）；要「开通 → 模板 → 团队」全流程看 xilo 万字（#7）和想风/麦当的零基础篇（#6/#8）。

3. **接到日常入口（分类三）**  
   微信转发（#9）、飞书组 X 内容团队（#10）、或 iPhone/Mac Webhook+快捷指令（#11）——选一个你每天真会打开的入口。

4. **稳住云环境（分类四 + 五）**  
   自带云电脑能做什么、能不能当服务器（#13）；要 SSH 再看（#12）。需要 7×24 Claude Code 时再上 Asa 的 Orca + Tailscale（#14）和 Claude 订阅指南（#15）。

5. **上规模再谈分工与内容（分类六 + 七）**  
   首席助理统筹十几个专职 Bot（#16）→ 自媒体流水线 / 五层内容架构 / 爆款监控 Skill（#17–#20）。

6. **工程化与保命（分类八 + 九）**  
   Cursor + pstack（#21）、工程师用法（#22）、记忆与设定 Git 备份（#23）——更新 Bot 电脑或换机前先备好。玩法向可看 JEV × GrokBot × X（#24）。
