# 履历喂 AI 挖隐藏变现机会的七条提示词

## 一句话定位

把**真实薪资 + 工作经历**喂给大模型，用固定的七条指令依次挖：被低估的技能 → 副业切口 → 可卖的产品/服务 → 最大杠杆 → 更高薪角色 → 每周不足 5 小时 的 AI 辅助副业 → 90 天行动计划。杨竹筠这条抖音是对外网「Raúl / 同句式病毒帖」七条模板的中文口播演示（约 1 分 44 秒）。

## 上手顺序（照做）

1. **准备输入包**（必做）：近 5–10 年履历要点、当前岗位与薪资区间、每周可投入小时数、不想碰的行业/红线。没有履历就先列「做过的事 + 结果数字」。
2. **开一个新对话**（ChatGPT / Claude / 豆包 / Grok 均可），先把履历整段贴上，再说明「后面所有指令都基于这段经历」。
3. **按 1→7 顺序跑**（不要跳着玩）：每条等模型答完再贴下一条；第 2 条金额可改成自己的目标（作者口播建议）。
4. **收敛**：从第 2、3、6 条里各圈 1–2 个「愿意本周试」的选项，交给第 7 条出 90 天逐步计划。
5. **落地检验**：第 4 条的「最大杠杆」若和第 7 条第一步对不上，以「本周能开工、且不依赖新学历」的那条为准。

## 可复制提示词（屏幕原样）

> 使用时把「下面的职业经历」换成你刚贴的履历；金额可改。

### 1 · 发现我的隐藏技能

```
基于我下面的职业经历，识别出我低估的10种最有价值的技能。解释为什么它们有价值，谁会为它们付费，以及AI如何帮助我将其货币化。
```

### 2 · 寻找收入机会

```
基于你的经验，建议10种现实的方式，让我每月额外赚取1,000–3,000美元。包括启动成本、时间投入、难度水平和收入潜力
```

### 3 · 变现我的经验

```
充当一名企业战略家。基于我的工作经历，识别出我可以利用已掌握技能创建的服务、咨询产品、数字产品或自由职业工作机会
```

### 4 · 找到我最大的杠杆机会

```
如果你要帮助我尽可能快地增加我的收入，利用我当前的能力，你会首先关注什么，为什么？
```

### 5 · 向我展示什么薪水更高

```
根据我的经验，识别出那些薪水显著高于我当前职位的角色、行业或机会。解释是什么让我有资格胜任。
```

### 6 · 创建一个由 AI 驱动的副收入来源

```
利用我的技能和背景，建议5个由AI辅助的服务，我可以提供这些服务，每周启动所需时间不到5小时
```

### 7 · 构建我的 90 天计划

```
如果我的目标是在接下来的90天内创造更多的职业安全感和额外收入，请基于我的职业经历、时间安排和经验，创建一个逐步计划
```

| 能力 | 有没有 | 说明 |

| 可复制完整提示词 | ✅ | 屏幕七条中文 + 附录英源 |
| 操作顺序 | ✅ | 1→7；先履历后指令 |
| 亲测案例细节 | ⚠️ | 作者称「试了一下发现新大陆」，**未展开她个人输出样例** |
| 「3 亿围观」核验 | ❌ | 传播话术；对应外网多账号同句式转发累计曝光，非单帖 UV |
| 变现承诺 | ❌ | 无收益保证；输出质量强依赖履历真实度 |

## 坑

- **空履历硬跑**：模型会编「看起来合理」的技能与报价；务必先喂具体项目与结果。
- **把第 2 条当发财保证**：$1k–3k/月是模板里的目标区间，不是作者或外网博主的实测账单。
- **跳过第 4/7 条**：只收藏提示词不收敛，容易停在「想法清单」。
- **混用账号口径**：杨竹筠屏幕中文 ≈ 英源同构翻译；引用时写清是「杨竹筠演示」还是「英源原文」。
- **隐私**：薪资与公司名可脱敏后再喂公有模型。

## 适合谁

- 有一定职场积累、想用 AI 做**副业切口盘点**或**跳槽方向探测**的人  
- 需要一套「可直接粘贴」的自我盘点提示词，而不是抽象提示词课  

不适合：指望一条视频给出「稳赚项目」或替代真实市场验证的人。
