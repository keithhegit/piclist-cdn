## 工具分工

这套实验用到的工具很精简：

- **Claude Code** — 在命令行 headless 模式下自动跑完全程，管理文件读写、缓存设置和预算上限
- **Fable 5.2** — 写 WebAudio 音频合成代码、Three.js 着色器、顶点建模和游戏逻辑
- **agent-browser** — 让 AI 在本机 Chrome 里打开自己写的网页截图自检、看控制台报错、检查 WebGL GPU 渲染器
- **OfflineAudioContext** — 浏览器离线音频渲染接口，让听不见声音的 AI 把音频渲染出来，检查峰值、削波和静音段

## 16.6 分钟做出音效台

第一次试不用一上来就跑完整的 FPS 游戏，先用最小的音效台把命令行无人值守流程跑通，折算成本 $4.66。

1. **准备环境（2 分钟）** — 确保 Claude Code 升级到 2.1.242 以上版本（我用的是 2.1.322），本机装好 Chrome 和 agent-browser；
2. **新建两个文件（2 分钟）** — 在一个空文件夹里，新建 builder_system.md（放附加的系统提示词）和 prompt.md（放具体任务需求）；
3. **写入系统提示词（1 分钟）** — 把下面这段话存进 builder_system.md，让 AI 自己截图和查音频 👇

```
你在独立完成一个创作任务。用户只给一次需求，之后不会再回答任何问题，所有决定你自己做，直到作品完成。
- 产物只写到任务指定的目录。
- 可以用 `agent-browser`（open / screenshot / eval / console）在本机 Chrome 里打开自己的页面截图自检，发现问题就改。截图前先用 eval 读一次 WebGL renderer 字符串，如果是 SwiftShader 等软件渲染，在最终汇报里写明。
- 涉及声音时，你听不到声音：用 OfflineAudioContext 渲染后检查峰值、削波和静音段，在汇报里写明「未经人耳试听」。
- 完成后用 3–6 行汇报：做了什么、文件路径、已知问题。
```

4. **执行命令行（1 分钟启动，跑 16.6 分钟）** — 把后面“板块一”的音效提示词放进 prompt.md，在终端运行下面这条命令，等它自己跑完即可 👇

Agent执行如下命令：

```
claude -p "$(cat prompt.md)" \
  --model claude-fable-5-2 \
  --permission-mode auto \
  --append-system-prompt "$(cat builder_system.md)" \
  --settings '{"promptCacheTtl":"5m"}' \
  --max-budget-usd 12 \
  --output-format json > run.json
```

## 板块一：纯代码合成游戏音效台

### 为什么先做这一步
