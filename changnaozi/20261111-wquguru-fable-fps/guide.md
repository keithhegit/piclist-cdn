# Claude Code + Fable 5.2 纯代码生成浏览器 FPS

这篇攻略摘要对应 @wquguru 的 X Article《Fable 5.2 从建模到 FPS 游戏完整教程》。提示词与命令以原文为准，可与 `transcript.md` 对照。

## 一句话定位

用 Claude Code 的 headless 无人值守模式调用 Fable 5.2，只给一次需求、配上自检系统提示词，就能在浏览器里纯代码生成音效、程序化材质、工业级模型和一整款迷你 FPS，全程不加载外部模型、贴图或音频文件。

## 适合谁

- 想用 Claude Code / Fable 5.2 做可玩的 Web 小游戏或程序化资产，不想手写 Three.js / WebAudio
- 想先用低成本小实验跑通「写文件 → 浏览器截图自检 → 离线音频检查」这条 agent 流水线
- 不适合：没有 Claude Code、本机 Chrome 和 agent-browser，或预算撑不住单次约 $5–$16（走缓存）乃至更高（不走缓存）的人

## 上手顺序

1. **先跑最小实验（约 16.6 分钟，折算 $4.66）**：不要一上来就做完整 FPS。准备环境 → 写两个文件 → 启动命令，只做音效台。
2. **准备环境（约 2 分钟）**：Claude Code ≥ 2.1.242（作者用的是 2.1.322），本机装好 Chrome 和 `agent-browser`。
3. **空目录里新建两个文件（约 2 分钟）**：`builder_system.md`（自检系统提示词）和 `prompt.md`（当次任务）。
4. **写入系统提示词（约 1 分钟）**：把下文「系统提示词」原样放进 `builder_system.md`。
5. **把板块一提示词放进 `prompt.md`，跑命令**：作者开 5 分钟缓存、`--max-budget-usd 12`。等它自己跑完。
6. **再按需加码**：同一套系统提示词，换 `prompt.md` 分别跑材质、模型；最后换到干净空目录，用 Felix 原版那句一句话提示词跑完整 FPS（作者开 1 小时缓存，约 40.8 分钟，折算 $15.96）。

启动命令（原文）：

```bash
claude -p "$(cat prompt.md)" \
  --model claude-fable-5-2 \
  --permission-mode auto \
  --append-system-prompt "$(cat builder_system.md)" \
  --settings '{"promptCacheTtl":"5m"}' \
  --max-budget-usd 12 \
  --output-format json > run.json
```

完整 FPS 那一轮作者把缓存改成了 1 小时（正文写「开了 1 小时缓存」），命令里的 `promptCacheTtl` 需按当次目标自行调整；预算上限原文示例是 `$12`，完整 FPS 不走缓存的原价作者记为 $60.57，实际跑时要把 `--max-budget-usd` 留够。

工具分工：

- **Claude Code**：命令行 headless，管文件、缓存和预算
- **Fable 5.2**：写 WebAudio、Three.js 着色器、顶点建模和游戏逻辑
- **agent-browser**：在本机 Chrome 里打开页面截图、看控制台、检查 WebGL renderer 字符串
- **OfflineAudioContext**：让听不见声音的模型把音频渲染出来，查峰值、削波和静音段

## 可复制提示词

以下均录自原文代码块，未改写。

### 系统提示词（写入 `builder_system.md`）

```
你在独立完成一个创作任务。用户只给一次需求，之后不会再回答任何问题，所有决定你自己做，直到作品完成。
- 产物只写到任务指定的目录。
- 可以用 `agent-browser`（open / screenshot / eval / console）在本机 Chrome 里打开自己的页面截图自检，发现问题就改。截图前先用 eval 读一次 WebGL renderer 字符串，如果是 SwiftShader 等软件渲染，在最终汇报里写明。
- 涉及声音时，你听不到声音：用 OfflineAudioContext 渲染后检查峰值、削波和静音段，在汇报里写明「未经人耳试听」。
- 完成后用 3–6 行汇报：做了什么、文件路径、已知问题。
```

### 板块一：纯代码合成游戏音效台（写入 `prompt.md`，输出 `./01-audio/index.html`）

```
用纯 WebAudio 代码合成一套 FPS 游戏音效，不许用任何音频文件、采样或外部音频库，所有声音都从振荡器、噪声和滤波器算出来。

要有：步枪单发（室外、室内两种尾音）、换弹三段（退弹匣、上弹匣、拉枪栓）、弹壳落地、脚步（水泥、金属、积水各一种）、子弹掠过耳边、跳弹、持续的雨声、远处的雷声、一段 30 秒左右的紧张配乐。每个音效至少 3 个随机变体，连按不会听起来一模一样。

品质要像 3A 游戏的音效，不要 8-bit 芯片音那种味道。

做成一个单文件 HTML 音效台：每个声音一个按钮，播放时显示波形和频谱，界面要好看。
输出到：./01-audio/index.html
```

### 板块二：程序化雨夜码头材质（输出 `./02-materials/index.html`）

```
用 Three.js（从 CDN 引入，只允许这一个库）做一个材质展示页，所有贴图都必须在代码里程序化生成，不许加载任何图片文件。

材质：雨后湿漉漉带积水反光的混凝土地面、刷漆后生锈的集装箱瓦楞钢板（带喷涂的箱号和标识）、镀锌钢、黑色橡胶、木托盘、带做旧痕迹的金属铭牌。

光照是雨夜码头的氛围：钠灯暖光加冷色天光，环境反射也要程序化生成。画面要接近照片级写实，可以慢慢转动查看每个材质。

做成单文件 HTML，输出到：./02-materials/index.html
```

### 板块三：纯代码建模岸桥、货船与步枪（输出 `./03-models/index.html`）

```
用 Three.js（从 CDN 引入，只允许这一个库）纯代码建模，不许加载任何模型文件或图片：
1. 一台集装箱码头的岸桥起重机（桁架、吊具、司机室、钢缆都要有）
2. 一艘停靠的集装箱货船，甲板上堆着集装箱
3. 一把第一人称视角的突击步枪，带红点瞄具，细节要经得起近看

结构比例要像真的，细节越多越好。做成单文件 HTML 模型查看器，可以切换三个模型、鼠标旋转缩放。
输出到：./03-models/index.html
```

### 板块四：一句话跑出完整 FPS（输出 `./out/index.html`）

作者说明：这是 Felix 原版提示词，去掉了开头的 `You know, you should also`，另加了一句单文件 HTML、只用 CDN、不加载外部文件的环境说明。放到干净空目录再跑。

```
Build me a FPS. Insanely detailed quality pls, something that looks visually like it can keep up with AAA. Make it small in scope (like a tiny level) but otherwise impressive photorealistic graphics

（环境说明：做成浏览器里能玩的单文件 HTML，只能从 CDN 引入库，不能加载外部模型、图片、音频文件。输出到 ./out/index.html）
```

中文对照（不替代原文）：给我做一款 FPS。画质请尽量离谱地细，视觉上要能跟 3A 叫板。范围可以很小（比如一个迷你关卡），但除此之外要有令人印象深刻的照片级写实画面。

## 坑

- **不要一上来就跑完整 FPS**。先用音效台验证命令行、缓存和自检是否通。完整 FPS 不走缓存作者记为 $60.57，走 1 小时缓存才折到 $15.96；命令示例里的 `--max-budget-usd 12` 不够这一趟，要改大。
- **缓存命中率决定账单**。音效台 88.6%、材质 83.8%、建模 76.1%、FPS 90.9%。作者把完整 FPS 的 90.9% 对照自己倒推原版的 90%–95% 区间。缓存时长要按当次任务改（预热 5 分钟，完整 FPS 1 小时）。
- **模型听不见声音、也看不见真实 GPU 画面**。必须靠系统提示词强制：用 OfflineAudioContext 查峰值/削波/静音，并写明「未经人耳试听」；截图前用 `eval` 读 WebGL renderer，若是 SwiftShader 等软件渲染要写进汇报。作者材质实验测到的是 Apple M2 Pro 真 GPU。
- **提示词禁止外部资源，结果仍会「超纲」**。音效台多了「交火演示」按钮；模型查看器多了「码头全景」。这是能力，也可能偏离你的目录和范围预期。
- **作者自报的画面缺陷不要当已修好**：材质「部分小坑被误判为积水、远景箱堆是平涂色块」；步枪「第一人称没有手臂」；FPS「前臂和手套比较简陋、反射只有地面」。
- **开篇视频不能当游戏音效样片**。那是 SUBLEVEL 07 实机画面，配乐是后加的 CC0 电子乐，游戏本身的 18 个代码音效没有录进去。
- **软件渲染会让「照片级」判断失真**。系统提示词要求把 renderer 字符串写进最终汇报，不要只看截图。
