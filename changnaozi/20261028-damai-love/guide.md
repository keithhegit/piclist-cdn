## 一句话定位

作者不教「怎么追人」，而是用自身经历把爱情从「星座/MBTI/依恋类型算题」拉回「体验」：六条都在讲**怎么和另一个独立的人长期相处**——独立、空间、付出、深度沟通、持续吸引、外界意见归自己；收在「爱情不是拿来搞懂的，是拿来经历的」。

## 适合谁

- 刚分手、把对方当全部、怕「再也遇不到更好」的人  
- 长期关系里为「想独处」互相误解、或默默记账本的人  
- 短视频选题：亲密关系边界 / 深度沟通 / 吸引力经营 / 别人意见 vs 自己决定

## 上手顺序（建议 7 天）

1. **今天改标签**：把「我要搞懂爱情」改成「我先经历、再复盘」；暂停用模型替自己回答「我爱不爱他」。  
2. **本周自查六条**（对应片中主题，操作层来自二次梳理）：  
   1. **独立**：人生不全押在对方身上；「我一个人也能过，但仍希望你在」  
   2. **空间**：约定可独处时段；对方要空间 ≠ 不爱你  
   3. **付出**：区分「真心想做」与「偷偷换回报」；有期待就说，不假装无私  
   4. **沟通**：日常闲聊之外，聊一次「我们想不想过同一种生活」（钱/城市/孩子/边界）  
   5. **吸引**：不为「反正不会走」停更自己；兴趣/运动/好奇继续在线  
   6. **外界意见**：可倾诉，但决定权收回自己；别只跟朋友吐槽、从不跟伴侣谈  
3. **可选实验（戈特曼启发五问）**：先自己默答，再问对方——最近最烦恼 / 最期待 / 最想吃的一顿饭 / 最怕失去什么 / 最想改变生活里的哪一件。不对分，只看「我是否已经很久没更新对他的了解」。  
4. **验收**：不做大目标；只看「自责/猜忌是否下降 + 是否完成 1 次深度沟通或 1 次独处边界澄清」。

## 能力表 / 核心论点

| 论点 | 可操作含义 |
|---|---|
| 爱情可解释，但解释不完 | 工具辅助理解；别让模型替你判断爱不爱 |
| 独立 ≠ 冷血 | 完整的自己，才有能力爱，而不是互相供养恐惧 |
| 空间是关系前提 | 独处先消化情绪，再沟通，少在情绪顶点互攻 |
| 付出别暗账 | 期待说出口；「懂我你就该知道」很危险 |
| 深度沟通 > 报备刷屏 | 确认「同一种生活」，不只确认「你爱我」 |
| 稳定后别停经营自己 | 吸引是「还在生活」，不是永远二十岁身材 |
| 意见可听，决定自持 | 朋友听到的多是你气头上的版本 |
| 经历 > 搞懂 | 说不清楚才正常；具体瞬间比公式迷人 |
